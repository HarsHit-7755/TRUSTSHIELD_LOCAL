METHOD

What gets checked

Each indicator is explained so the result is inspectable, not a mysterious verdict.

01

URL structure

Checks protocol, hostname patterns, IP-address destinations, subdomains, ports and encoded characters.

02

Deception signals

Looks for suspicious wording, short links, Punycode and possible brand-like text in the hostname.

03

Threat reputation

Optionally checks for an exact URL match in URLhaus when a server-side API key is configured.

Important limitation

TRUSTSHIELD is an educational prototype. It does not visit or inspect page content, downloads, redirects, DNS, TLS certificates or domain registration records. A low score or missing URLhaus match does not establish that a website is safe.
